# Reviews

One file per weekly review, written by the agent.

**Gitignored.** Reviews quote your logs.

A review reads the week's logs against the programme and answers three questions:

1. **Did the anchors progress as planned?** If not, was it fatigue, illness, or too big a jump?
2. **What was skipped, and why?** A pattern of skipping the same session is a design problem, not
   a discipline problem.
3. **What changes next week?**

The difference between `programme/` and `logs/` is the most valuable data in the repo. The plan
alone is a guess; the log alone is a diary.
